# Bluetooth-control-car
Arduino based bluetooth control car using hc-05 module and l298N motor driver

## 🧰 Components Used
- Arduino Uno  
- HC-05 Bluetooth Module  
- L298N Motor Driver  
- 2 DC Motors  
- Wheels & Chassis  
- Battery  
- Jumper Wires  

## ⚙️ Working
The HC-05 module receives commands from a mobile app and sends them to Arduino. Arduino processes the commands and controls the motors using L298N motor driver.

## 🎮 Controls
- F → Forward  
- B → Backward  
- L → Left  
- R → Right  
- S → Stop
